# 📱 Phone & Lifestyle Extension for SillyTavern

ส่วนขยายโทรศัพท์เสมือนสำหรับ SillyTavern พร้อมฟีเจอร์ครบครัน!

## ✨ ฟีเจอร์หลัก

### 📱 ปุ่มลอย (Floating Button)
- ลากย้ายได้ทุกมุมของหน้าจอ
- แสดงไอคอนรูปภาพที่กำหนด
- มีแจ้งเตือน badge

### 📲 แอพในโทรศัพท์
| แอพ | ฟีเจอร์ |
|-----|---------|
| **Instagram** | โพสต์รูป, สตอรี่, DM, โทรวิดีโอ, โปรไฟล์, ติดตาม, ไลก์, คอมเมนต์ |
| **LINE** | แชท, สติ๊กเกอร์, โทร, วิดีโอคอล, ส่งรูป |
| **🎵 เพลง** | เพิ่มเพลงจาก YouTube URL, เล่น/หยุด, ข้าม, ปรับเสียง, ดูวิดีโอ |
| **🏦 ธนาคาร** | ดูยอดเงิน, โอนเงิน, เติมเงิน, ดูประวัติรายรับรายจ่าย |
| **Twitter/X** | ทวีต, ไลก์, รีทวีต, ตอบกลับ, ติดตาม |
| **TikTok** | ดูคลิป, ไลก์, คอมเมนต์, อัปโหลดคลิป |

### 🐾 ระบบสัตว์เลี้ยง
- เลือกสัตว์เลี้ยงได้ 6 ชนิด: แมว, หมา, กระต่าย, แฮมสเตอร์, นก, สุนัขจิ้งจอก
- ระบบหิว/สุข/พลังงาน/ความสะอาด
- กิจกรรม: ให้อาหาร, เล่น, นอน, อาบน้ำ, กอด
- **ไม่กระทบการแชทกับตัวละคร**

### 📝 บันทึก
- เพิ่ม/แก้ไข/ลบบันทึกได้ไม่จำกัด
- บันทึกแยกตามตัวละครที่กำลังเล่น

## 🔔 ระบบแจ้งเตือน
- แจ้งเตือน toast แบบ popup
- ตัวละคร (Char) และ NPC จะส่งข้อความและโต้ตอบอัตโนมัติ
- แต่ละตัวละครมีข้อมูลแยกกัน (Instagram, LINE, Twitter ฯลฯ)
- รีเซ็ตเมื่อเริ่มแชทใหม่กับตัวละครนั้น

## 📥 วิธีติดตั้ง

### วิธีที่ 1: ติดตั้งผ่าน SillyTavern Extensions Manager
1. เปิด SillyTavern
2. ไปที่ **Extensions** → **Install extension**
3. ใส่ URL ของ GitHub repo นี้
4. กด Install

### วิธีที่ 2: ติดตั้งด้วยตนเอง
1. Download หรือ Clone repo นี้
2. วางโฟลเดอร์ `phone-lifestyle` ลงใน:
   ```
   SillyTavern/public/scripts/extensions/third-party/phone-lifestyle/
   ```
3. รีสตาร์ท SillyTavern
4. ไปที่ **Extensions** แล้ว Enable "Phone & Lifestyle Extension"

## 📁 โครงสร้างไฟล์
```
phone-lifestyle/
├── manifest.json     # ข้อมูล extension
├── index.js          # JavaScript หลัก
├── style.css         # CSS styles
└── README.md         # คู่มือนี้
```

## 🎵 วิธีใช้แอพเพลง
1. กดปุ่มโทรศัพท์ → เลือก "เพลง" หรือเข้าจากในโทรศัพท์
2. กด **"+ เพิ่มเพลงจาก YouTube"**
3. วาง YouTube URL (เช่น `https://www.youtube.com/watch?v=xxxxx`)
4. ตั้งชื่อเพลง (ไม่บังคับ) แล้วกด **เพิ่ม**
5. เพลงจะเล่นพร้อมวิดีโอ YouTube โดยตรง

## 📊 ข้อมูลตัวละคร
- ข้อมูลทุกอย่าง (โพสต์ IG, แชท LINE, ทวีต, ยอดเงิน) **แยกตามตัวละครที่เล่น**
- เปลี่ยนตัวละคร → ข้อมูลจะเปลี่ยนตาม
- เริ่มแชทใหม่ → รีเซ็ตข้อมูล

## ⚠️ หมายเหตุ
- ระบบสัตว์เลี้ยงและเพลง **ไม่เชื่อมต่อกับ AI** เป็นระบบแยกต่างหาก
- แอพโซเชียล (IG, LINE, Twitter) ใช้ AI จำลองการตอบสนองของตัวละคร
- ต้องการ SillyTavern เวอร์ชัน 1.10.0 ขึ้นไป

## 🛠️ ความต้องการระบบ
- SillyTavern 1.10.0+
- Browser รองรับ ES6 Modules
- การเชื่อมต่ออินเตอร์เน็ต (สำหรับ YouTube player)
